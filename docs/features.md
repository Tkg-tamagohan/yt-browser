# yt-browser 機能一覧

実装済みの機能を領域ごとにまとめた一覧。
操作方法は [user-guide.md](user-guide.md)、要件は [requirements-definition.md](requirements-definition.md) の FR-1 以降、個別の判断は [decision-records.md](decision-records.md) の仕様決定を参照。
実装の内訳は [implementation-plan.md](implementation-plan.md) の Phase 0〜81 に対応する。

## 動画再生

- **URL / 動画 ID の再生**：トップ画面の入力欄に YouTube の URL または動画 ID を入れて再生する。
  再生位置を持つ履歴がある動画は「続きから再生」になり、前回位置から再開する（FR-1、FR-7。Phase 1、22）。
- **複数インスタンスの同時再生**：再生ごとに mpv プロセスを起動し、プレイヤーカードとして並べて制御する（FR-1。Phase 1、8）。
- **既定の PiP 小窓**：再生は既定で最前面かつ枠なしの PiP 小窓で始まる。
  設定 `pip.default` で通常窓を既定に戻せる（FR-18。Phase 25）。
- **プレイヤーカードの操作**：一時停止と再開、シーク、音量、速度、インスタンス別の画質と音声出力先、1 コマ送りと戻り、PiP 化と解除、終了、タイトルとリンクのコピー（FR-1、FR-14、FR-32、FR-34。Phase 2、13、40、42）。
- **コマ送り**：一時停止中はホイール、mpv の `,` / `.` キー、カードのボタンでフレーム単位に前後へ移動し、操作中は無音になる（FR-2、FR-22。Phase 2、28）。
- **ホイールの既定割り当て**：mpv 窓上では再生中が音量、一時停止中がコマ送り。
  ノッチあたりの音量変化量は設定できる（FR-2。Phase 2）。
- **ループ再生**：カードのループボタンで「なし」「全体」「1 項目」を切り替える（FR-16。Phase 17）。
- **概要欄**：カードから再生中動画の概要欄を開き、本文中の URL は既定ブラウザで開き、時刻表記はその位置へシークする（FR-33。Phase 41）。
- **リンクコピー**：「リンクをコピー」はタイトルと視聴ページ URL をクリップボードへコピーする（FR-34。Phase 42）。
- **SponsorBlock と区間表示**：SponsorBlock API から区間を取得して自動スキップや通知ができ、独自シークバー上に色帯で区間を表示する。
  設定画面でカテゴリ別の動作と `sponsor.show_segments` の表示有無を切り替えられる（FR-8、FR-36、BG-8。Phase 3、47）。
- **ロード失敗時の自動再試行**：初回読込完了前にエラー終端となった場合は約 1.5 秒後に 1 回だけ自動で再試行する（BG-9。Phase 48）。
- **A-B リピートとスクリーンショット**：カードの「AB」ボタンで区間ループを巡回し、スクリーンショット操作で字幕込み PNG を保存して保存先を開ける（FR-37、FR-38。Phase 51）。
- **初期再生設定と字幕選択**：設定 `player.initial_speed` と `player.initial_volume` で新規再生時の既定値を指定でき、再生中は字幕トラックを切り替えられる（FR-39、FR-40。Phase 52）。
- **窓の前面化と自動クローズ**：カードから mpv 窓を前面へ呼び出せ（Wayland 除く）、設定 `player.close_on_eof` で再生完了時の自動クローズを切り替えられる（FR-42、FR-43。Phase 54、55）。
- **動画内ブックマーク**：再生中の現在位置にラベル付きブックマークを保存し、一覧からジャンプや編集や削除ができる（FR-49。Phase 59）。
- **ライブ配信の待機**：放送開始前の配信を待機リストへ登録し、開始検出時に設定 `live_wait.action` に応じて自動再生または通知を行う（FR-44。Phase 56）。

## キューと連続再生

- **一時キュー**：各一覧の動画行にある「キューに追加」で末尾へ、「次に再生」で現在位置の直後へ積み、パネルの「再生」で連続再生を始める（FR-20、FR-26。Phase 31、34）。
- **キューの編集と操作**：項目は上下ボタンとドラッグ＆ドロップで並べ替え、個別削除と全消去ができ、「残りをシャッフル」で未再生分をランダム化できる。
  項目には一意の `uid` を持ち、同一動画を連続登録しても現在位置がずれない（FR-20、FR-45、FR-46、BG-10。Phase 31、49、57）。
- **キューの永続化**：一時キューだけでなくプレイリストキューも DB（`queue_items` と `queue_state`）に保存され、アプリ再起動後は停止状態で復元される（FR-30、FR-48、仕様決定 AY、BY。Phase 38、58）。
- **プレイリストキューと保存**：「ここから連続再生」でプレイリストごとのキューを作り、複数キューを別々のプレイヤーで同時に連続再生できる。
  「プレイリストとして保存」で選択中キューを新規プレイリストへ複製できる（FR-10、FR-26、FR-47。Phase 14、34、58）。
- **キューの寿命**：一時キューとプレイリストキューのいずれも、停止中は位置を保持して再開でき、消費完了では先頭へ戻り、窓を閉じるなどのインスタンス終了時に消滅する（FR-26、FR-48、仕様決定 BY。Phase 34、58）。
- **キーボードショートカット**：設定 `ui.shortcuts` をオンにすると、一覧の動画行を `j` / `↓`・`k` / `↑` で選択し、`Enter` で再生、`a` でキューに追加できる。`q` でキューパネルを開閉する（既定はオフ。FR-79。Phase 72）。

## 購読フィード

- **チャンネル購読**：チャンネル ID、URL、@handle で購読し、カテゴリ分けとカテゴリの並べ替えと解除ができる（FR-3、FR-63。Phase 4、11、66）。
- **新着ポーリングと通知**：チャンネル RSS を ETag / Last-Modified 付きで定期取得し、新着は未読として一覧に積む。
  設定 `feed.notify_new` が有効なら新着を OS 通知する（FR-3、FR-58。Phase 4、65）。
- **既読管理と自動既読**：個別既読と「すべて既読」、チャンネル名クリックによる即時再取得とそのチャンネルへの絞り込みができる。
  設定 `feed.auto_read_played` と `feed.auto_read_days` で再生済み動画と古い未読の自動既読化を有効化でき、削除や一部操作はトーストの「元に戻す」で取り消せる（FR-3、FR-21、FR-54、FR-64。Phase 4、32、63、65）。
- **フィルタと表示**：未読のみ、カテゴリ、種別（動画、Shorts、ライブ）、チャンネル別セクション表示に対応する。
  Shorts は既定で非表示（FR-13、FR-21、FR-23。Phase 11、29、32）。
- **ページング**：一覧末尾の「さらに読み込む」で古い方向へ 500 件ずつ追記する（FR-25。Phase 30）。
- **過去動画のバックフィル**：チャンネル絞り込み中に yt-dlp の flat-playlist で `/videos`、`/streams`、`/shorts` タブを遡って取り込み、既読として保存する（FR-21、FR-55。Phase 32、63）。

## 検索と関連動画

- **キーワード検索**：yt-dlp の ytsearch で検索し、結果は「さらに読み込む」で 20 件ずつ最大 500 件まで追加できる（FR-4、FR-25。Phase 5、30）。
- **行アクション**：検索結果から再生、購読、ブロックへ遷移できる（FR-4、FR-5。Phase 5）。
- **関連動画**：再生中カードの「関連動画を表示」で InnerTube `next` の関連動画を開く（FR-4。Phase 5）。

## チャンネルブロックと NG フィルタ

- **チャンネルブロック**：ブロックしたチャンネルの動画をフィード、検索、関連動画から除外し、設定画面で解除する（FR-5。Phase 5）。
- **NG フィルタとハイライト**：動画タイトル、動画説明文、チャンネル名、チャンネル ID、チャット本文、チャット投稿者を対象に、部分一致、正規表現、チャットのキーワード強調表示（`highlight`）を追加と削除できる。
  `chat_author` の部分一致向けには設定画面へ NG ユーザー専用の管理節を用意している。
  動画説明文は InnerTube メタ応答から遅延解決で `videos` テーブルへ保存され、説明文を持つ項目で評価される（FR-9、FR-69、FR-70、FR-85。Phase 6、68、76）。
  説明文の未解決な項目と、説明文を持たない取得経路（検索や関連動画）では評価されない。

## ライブチャット

- **リアルタイム表示**：InnerTube `get_live_chat` の継続トークンポーラーでライブチャットを流し、スーパーチャット、メンバーシップ通知、削除済みメッセージを表示する（FR-6。Phase 6）。
- **チャットリプレイ**：終了済み配信やプレミア公開では、リプレイを再生位置に同期して流し、シークで再アンカーする。
  プレミア公開ではリプレイ先頭発言との差から前置きオフセットを実測補正できる（FR-24、FR-71。Phase 33、69）。
- **チャットポップアップ**：チャットを別ウィンドウへ切り離し、最前面固定の切り替えとパネルへの復帰ができ、位置とサイズ（`chat.popup_geometry`）を保存して復元する。
  投稿者名の表示有無、文字サイズ、背景不透明度を設定画面から調整できる（FR-27、FR-67、FR-68。Phase 35、67）。
- **チャットの非保存**：チャットメッセージはライブとリプレイの双方で DB に保存しない（仕様決定 AV。Phase 36）。

## ライブラリ

- **視聴履歴**：視聴した動画を途中再生の位置つきで記録し、再生、一時停止中カードの復元、「先頭から再生」、削除（取り消し可）ができる。
  履歴一覧はカーソルページングとキーワード検索に対応し、DB 保持は起動時に直近 10000 件へ剪定する（FR-7、FR-52、FR-54、FR-61。Phase 1、36、61、63）。
- **お気に入り**：動画をブックマークとして登録と解除ができ、並び順と絞り込みを切り替えて一覧できる（FR-7、FR-57。Phase 7、62）。
- **あとで見る**：行アクションから「あとで見る」へ登録と解除ができ、専用タブで一覧できる（FR-59。Phase 64）。
- **プレイリスト**：任意の一覧を作成と改名と削除ができ、動画を追加と削除できる（FR-7。Phase 7）。
- **YouTube プレイリストの取り込みと遅延解決**：プレイリスト URL をローカルプレイリストへ取り込み、表示中の画面へ即時反映する。
  未取得の投稿日時と動画種別（`video` / `live` / `upcoming` / `premiere`、shorts リトライ含む）はバックグラウンドで段階的に遅延解決する（FR-10、FR-53、FR-56、FR-57。Phase 14、24、62）。
- **項目の並べ替えとソート**：項目は上下ボタンとドラッグ＆ドロップで並べ替えて保存でき、投稿日時の昇順ソートと逆順化ができる（FR-11。Phase 14、16）。
- **プレイリスト一覧の並べ替え**：プレイリストそのものも上下ボタンとドラッグ＆ドロップで並べ替えて保存できる（FR-35。Phase 45）。
- **ライブラリ横断検索と視聴統計**：履歴、お気に入り、プレイリスト、あとで見るを横断検索でき、視聴履歴から累計視聴時間、チャンネル別、日別の統計を集計表示できる（FR-60、FR-65。Phase 64、66）。
- **履歴行の行アクション**：履歴の各行からお気に入り登録、プレイリストへの追加、キューへの追加ができる（FR-28。Phase 37）。
- **行のコンテキストメニュー**：動画行の右クリックで、行アクション「＋」と同じプレイリスト追加メニューをクリック位置に開く。
  フィード、検索、関連動画、ライブラリの各行で使える（FR-78。Phase 72）。

## 再生品質と表示

- **画質設定**：プリセット（1080p 上限、1080p60 優先、AV1 優先、最高画質）または自由記述のフォーマット式を設定する。
  稼働中インスタンスごとの変更はセッション内に限り有効（FR-1、FR-14。Phase 2、13）。
- **PiP の既定画質**：PiP 起動インスタンス専用の既定画質式を設定でき、未設定は全体の画質設定に従う（FR-14。Phase 13）。
- **PiP の位置とサイズと整列**：`pip.geometry` で小窓の位置とサイズを指定でき、「小窓サイズを動画のアスペクト比に合わせる」で動画の比率へ追従し、開いている複数の PiP 窓を格子状に一括整列できる（FR-19、FR-41。Phase 8、27、53）。
- **起動ディスプレイ選択**：再生窓を開くディスプレイを接続中モニターから選択でき、未設定や切断時は mpv 既定に戻る（FR-31。Phase 39）。
- **テーマと表示密度と設定検索**：カラーテーマ（`dark` / `light` / `system`）と一覧の表示密度（`comfortable` / `compact`）を切り替えられ、設定画面上部の検索欄から設定節を絞り込める（FR-73、FR-76、FR-77。Phase 70、71）。

## HDR と mpv の調整

- **HDR 設定**：トーンマッピング方式とピーク輝度計測を設定できる（INV-1、仕様決定 Y。Phase 15、21）。
- **mpv 追加引数**：`mpv.extra_args` で起動引数を末尾へ追加でき、HDR 対応を含む調整の受け皿になる（仕様決定 Y、AE。Phase 21）。
- **ストリーム読み取りタイムアウト**：`mpv.network_timeout_ms` で応答しない接続の待ち時間を変えられる（仕様決定 BE。Phase 44）。
- **HW デコード方式**：`mpv.hwdec` でハードウェアデコードを `auto-safe` などの受理集合から選べ、ドライバ起因の停止への回避策になる（仕様決定 BE。Phase 44）。
- **応答停止の自動復帰**：mpv が応答しなくなったときはウォッチドッグが検知して同一インスタンス内で再起動し、再生位置を復帰する（仕様決定 BE。Phase 44）。

## 外部連携

- **Chrome 拡張**：同梱の MV3 拡張から YouTube の動画とプレイリストを yt-browser で開くか一時キューへ追加できる。
  再生位置を引き継いでの再生や、ローカルプレイリストへの追加もでき、拡張ロジックの一部は `shared.js` と `shared.test.js` で単体検証する（FR-17、FR-29、FR-50、FR-51、BG-11。Phase 19、23、38、60、81）。
- **カスタム URL スキーム**：`yt-browser://` で動画は再生、プレイリストは取り込み、`yt-browser://queue` で一時キューへ、`yt-browser://playlist_add` でプレイリストへ追加する（FR-17、FR-29、FR-50。Phase 19、38、60）。
- **Native Messaging**：拡張はホストモード経由でアプリへ URL を渡し、確認ダイアログなしで開ける。プレイリスト一覧もホスト経由で取得する（仕様決定 AH、CA。Phase 23、60）。
- **ホスト定義の自己登録**：アプリ起動時にブラウザ別の置き場へ Native Messaging ホスト定義を自動登録する（対象は Chrome や Edge などの Chromium 系、仕様決定 AH と DM。Phase 23、79）。

## アプリの更新と基盤

- **自動更新**：AppImage と NSIS 版は起動時に更新を確認し、手動の確認ボタンもある。
  承認でダウンロードと適用と再起動を行う（FR-15。Phase 18、26）。
- **ローカル完結とデータ移行**：設定、履歴、購読、キューはローカルの SQLite に保存し、アカウント連携はない。
  購読やプレイリストや設定は JSON でエクスポートとインポートができ、運用節から DB サイズ確認、履歴全消去、VACUUM、孤児行整理を実行できる（FR-7、FR-30、FR-62、FR-66。Phase 7、66）。
- **多言語 UI**：i18n 基盤を持ち、設定 `ui.language` で日本語（`ja`）と英語（`en`）を切り替えられる（非機能要件、FR-81。Phase 0、74）。
- **依存コマンド設定と初回誘導**：`ytdlp.path` で任意の yt-dlp 実行ファイルを指定でき、`ytdlp.po_token` と引数プレビューを伴って診断節から `mpv`、`yt-dlp`、`deno` の状態を一覧でき、初回起動時はセットアップウィザードを表示する（FR-72、FR-74、FR-75、FR-86。Phase 70、77）。
- **診断情報出力と通知履歴**：ログやマスク済み設定を zip 形式でエクスポートでき、通知履歴を設定画面で一覧と消去できる（FR-82、FR-83。Phase 75）。
- **E2E 検証基盤と CI 追従**：Windows WebView2 向けの隔離 dev 起動と CDP 検証スクリプト一式を備え、CI は Node 24 対応 actions で検証する（FR-84、FR-87。Phase 78、80）。
- **mpv ログ**：全 spawn に `--log-file` を付与し、応答停止の事後調査に使える（仕様決定 BE。Phase 44）。

## 既知の制限

- NG フィルタの `video_desc` は遅延解決で保存した説明文だけを評価するため、説明文がまだ取れていない項目（取得前や説明文の無い動画）は除かれない。
  検索や関連動画の経路も説明文を持たないため評価されない（FR-85。Phase 76）。
- チャットメッセージは保存しないため、過去チャットの検索はない（仕様決定 AV）。
- その他の制限と観察メモは [implementation-plan.md](implementation-plan.md) の「残課題」節と [user-guide.md](user-guide.md) の「既知の制限」を参照。
